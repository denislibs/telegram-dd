How the closure was walked: a script parses the imports of every file under `src/global` (Babel), follows the relative
and `@teact` aliases, and stops at a module that reaches UI/teact code beyond the compat layer (teact hooks, `teact-dom`,
JSX components, `hooks/**`, `bundles/**`). Everything on this side of the stop is copied (about 50 util and helper files beyond `src/global`); what is behind it is cut by a FOUNDATION STUB (below). The compat layer here is: `teactn` → `global/index`, `fasterdom`/`heavyAnimation`/
`getIsHeavyAnimating`/`onFullyIdle`/`beginHeavyAnimation` → `frameact`, `TeactNode` → `lib/frameactNode`, `setExtraStyles`
→ `frameact/dom`.
